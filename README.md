## 1. 프로젝트 설명

🌿**Greeny**는 식물에 대한 다양한 정보를 얻을 수 있고, 식물의 성장 과정을 기록하고 공유할 수 있는 서비스입니다.

- **식물 백과**에서 다양한 식물들의 정보를 얻어보세요.
- **식물 일기**를 작성해 내 식물과 함께한 소중한 기억들을 기록해보세요.
- 다른 식집사들의 식물을 팔로우해 **성장 과정을 지켜보세요**.
- **커뮤니티**에서 다른 식집사들과 **정보를 공유**하며 가드닝 팁과 노하우를 얻어보세요.

    </td>
  </tr>
  <tr>
    <td>Sass</td>
    <td>

      1) 스타일과 마크업이 분리되어 <b>가독성 좋음</b><br>
      2) CSS-in-JS 방식은 런타임에 스타일을 선택하는 반면, Scss는 사전 컴파일되어 최종 CSS 파일로 변환되므로 브라우저의 부담이 줄어들어 <b>성능상 이점</b>이 있음
    </td>
  </tr>
  <tr>
    <td>Swiper</td>
    <td>여러 방식의 이미지 슬라이더 구현에 편리함이 있어서 사용</td>
  </tr>
  <tr>
    <td>lodash.isequal</td>
    <td>
      무한 스크롤이 적용된 페이지로 돌아갈 때 좋은 UX를 제공하기 위해 캐싱된 데이터로 화면을 먼저 보여줌<br>

      이 때 <b>객체의 깊은 비교를 위해 <code>lodash.isequal</code>을 사용함</b><br>
      그리고 업데이트된 내용이 있다면 업데이트된 데이터를 화면에 보여줌
    </td>

## 7. 트러블 슈팅

### 로그인

next-auth 모듈을 사용해서 로그인할 때, `signInWithCredentials` 함수 내부의 `redirect` 함수가 동작하지 않는 문제가 발생했습니다. <br>대체 방법으로 'next/navigation' 모듈로부터 `useRouter` 훅의 `push` 메서드를 통해 로그인 성공 시 페이지 이동을 하였고 리팩터링 때 원인을 파악해 해결할 예정입니다.

### Open API 사용

Open API를 통해 식물 데이터를 받아올 때 XML 방식 전달된 데이터를 JSON으로 파싱(xml2json 모듈 사용)하였고 불필요하고 정제가 필요한 값을 함수를 제작해 필터링하여 JSON 파일로 만들어 사용하였습니다.<br>
현재 방식은 데이터 통신이 없어 응답 속도가 빠르다는 장점이 있지만, 식물 데이터를 새로 추가하려 할 때면 새로 배포를 해야 하는 등 확장성 내지 유지보수 측면에서 분명한 단점이 있어서 앞으로는 일정 주기마다 Open API의 데이터 요청을 통해 DB를 최신화하는 리팩터링 작업을 진행할 예정입니다.
